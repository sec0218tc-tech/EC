# 임상 케이스 연습 사이트 기획서

소동물 임상 추론(문진 → 검사 → 감별진단 → 확정진단 → 처치)을 휴대폰으로 연습하는 웹앱.
기존 `web/` 코드는 참고만 하고, 이 기획에 맞춰 새로 만든다.

## 1. 목표와 사용 환경

- 처음엔 혼자 쓰고, 퀄리티가 괜찮으면 다른 사람과 공유한다.
- 주 사용 기기는 **휴대폰** → 모바일 우선 UI, 한국어.
- 핵심 목적: 확정진단뿐 아니라 **감별진단 목록**까지 맞히는 능력, 합리적인 **검사 순서**, 불필요한 검사 줄이기, **보호자 설득** 능력을 기른다.

## 2. 화면 흐름

```
케이스 목록(난이도별: 초급/고급)
 → 접수 (시그널먼트, 주호소)
 → 문진 (정해진 질문 목록 + 자유 질문)
 → 신체검사
 → 문제 목록(Problem list) 정리
 → 1차 감별진단
 → 추가검사 (전체 메뉴, 비용·시간 표시, 보호자 거부 시 설득)
 → 감별진단 수정 + 확정진단
 → 처치 (항목별 선택, 응급은 순서)
 → 항목별 채점과 해설
```

모든 단계에서 **진료 기록 패널**(바텀시트)을 아래에서 끌어올려 지금까지 얻은 정보를 볼 수 있다.

## 3. 단계별 상세

### 3.1 케이스 목록
- 난이도로 구분: **초급**(전형적 증상) / **고급**(동반 질환, 보호자 거부 등).
- 케이스마다 **검수 여부** 표시(교과서로 수치·처치를 확인했는지).
- 완료한 케이스는 점수 표시.

### 3.2 접수
- 시그널먼트(종, 품종, 나이, 성별·중성화, 체중)와 주호소.

### 3.3 문진
- 공통 질문 목록에서 골라 묻는다(케이스와 무관한 질문에도 자연스러운 답이 있다).
- **자유 질문**: 직접 입력하면 AI 보호자가 **케이스 정보 범위 안에서만** 답한다. 케이스에 없는 내용은 "잘 모르겠어요"처럼 답하고 새 사실을 지어내지 않는다.
- 꼭 물어야 할 질문(key)은 채점에 반영.

### 3.4 신체검사
- 모든 케이스에 같은 항목: 일반상태·BCS, 체온·심박·호흡·혈압(TPRBP), 탈수, 점막색, CRT, 맥박, 심폐 청진, 복부 촉진, 림프절, 구강, 눈·귀, 피부, 직장검사 등.
- 케이스와 무관한 항목은 정상 결과.

### 3.5 문제 목록
- 신체검사 후 이상 소견(예: 구토, 탈수 8%, 빈맥)을 정리한다.
- 문진·신체검사에서 찾은 소견 목록에서 고르는 방식. 놓친 핵심 문제는 채점·해설에 반영.

### 3.6 1차 감별진단
- **객관식 다중 선택**. 한 케이스에 선지 8~12개, 계통이 비슷한 질환을 섞어 선지가 힌트가 되지 않게 한다.
- 추가검사 결과를 볼 때마다 목록을 좁히거나 바꿀 수 있다.

### 3.7 추가검사
- **모든 케이스에 같은 전체 검사 메뉴**: CBC, 혈청화학, 전해질, 혈액가스, 젖산, 응고검사, UA·요비중·요배양, 신속 키트(CPV, FeLV/FIV, cPL 등), 방사선, 초음파, 심전도, 혈압, 특수검사(호르몬, PCR 등). 선지로 답을 짐작할 수 없게 한다.
- 케이스와 무관한 검사는 정상 결과.
- 검사마다 **비용과 소요 시간** 표시. 누적 비용 표시.
- 일부 케이스에서 보호자가 **비용이나 불신**으로 검사를 거부 → 사용자가 설득 문구를 입력 → AI가 설득 성공 여부를 판정(근거 설명 여부, 공감, 대안 제시 등 기준). 실패 시 다시 시도하거나 다른 검사로 우회.

### 3.8 감별진단 수정 + 확정진단
- 감별진단 목록을 최종 수정.
- 확정진단은 객관식. **동반 질환이 있는 케이스는 정답이 여러 개**일 수 있다(케이스를 그렇게 각색).

### 3.9 처치
- 객관식으로 항목별 선택: 수액 종류·속도, 약물, 입원/외래 여부 등.
- **응급 케이스**는 "먼저 할 처치"의 순서도 채점.

### 3.10 채점과 해설
항목별로 점수와 해설을 보여 준다.

| 항목 | 기준 |
|---|---|
| 문진 | 핵심 질문을 했는지 |
| 문제 목록 | 핵심 이상 소견을 빠뜨리지 않았는지 |
| 필수 검사 | 꼭 필요한 검사를 했는지 |
| 검사 순서 | 기본 검사 → 확진 검사 순서가 합리적인지 |
| 불필요 검사 | 불필요한 검사마다 감점(비용과 연결) |
| 설득 | 보호자 거부 시 설득에 성공했는지 |
| 감별진단 | 꼭 들어가야 할 것을 빠뜨렸는지, 엉뚱한 것을 넣었는지 |
| 확정진단 | 정답(들)을 맞혔는지 |
| 처치 | 적절한 처치 선택, 응급 시 순서 |

케이스마다 정답 감별 목록과 근거, 참고 문헌을 해설로 보여 준다.

## 4. 케이스 제작

- PubMed 등 실제 증례를 각색. 구하기 어려우면 AI로 생성한 뒤 본인이 검수.
- 케이스마다 **검수 칸**: 수치와 처치를 교과서로 확인했는지, 출처(문헌 DOI 또는 "AI 생성").
- 자료 조사: [`docs/cases-research.md`](cases-research.md) (PR #3).

## 5. 계정과 저장

- 1단계: 혼자 사용, 진행 기록은 브라우저에 저장.
- 2단계(공유 시): Supabase 로그인과 기록 저장. Supabase 프로젝트는 이미 저장소에 설정되어 있다.

## 6. AI 기능

- 자유 질문 답변(AI 보호자), 설득 판정에 LLM API가 필요하다.
- **비밀 키는 저장소에 커밋하지 않는다.** 서버(예: Supabase Edge Function)에서만 키를 쓰고, 브라우저는 그 서버를 호출한다.
- AI 기능이 없어도 나머지 흐름(목록 질문, 검사, 진단, 처치, 채점)은 동작해야 한다.
