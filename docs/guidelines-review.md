갑상선기능항진증 케이스는 다른 스레드가 Ettinger로 검사 순서를 보고 있어 건드리지 않았다.

## 교과서로 확인할 것

모든 케이스는 여전히 "교과서 검수 전"이다. 케이스 파일의 `review.todo`에 항목과 찾아볼 장(Ettinger 내과 / Fossum 외과)을 적었고, 결과 화면 끝에도 보인다.
특히 판단이 필요한 것:

- GDV: ENOVAT는 위고정술만 하면 예방 항생제를 권하지 않는데, 위벽 허혈이 있는 GDV에도 그대로 적용할지 (Fossum, GDV 장)
- 자궁축농증: 수술 후 항생제 기간, 아글레프리스톤 적응증 (WSAVA 지침은 초록이 없어 못 읽음)
- 파보: 항생제 기준. ENOVAT 급성 설사 지침은 초록만 읽어 파보에 적용되는지 확인 못 함
- MMVD: VETLIT 목록에 ACVIM 2019 성명이 없고 논평만 있음
- 지침의 용량 값(칼슘글루코네이트, 인슐린, 암로디핀, 텔미사르탄 등)이 교과서 판과 다른지

## 앱에서 보이는 근거 표시

- 결과 화면의 감별진단·처치 해설마다 "근거" 줄: 지침 이름(링크)과 확인 수준 배지. 근거가 없는 항목은 "교과서 수준 지식, 교과서 미대조"
- 출처·검수 영역: 출처마다 수준 배지, "교과서로 확인할 것" 목록
- 수준: 사용자 교과서 검수 > 전문 확인 > 전문 일부 확인 > 초록만 / 제목만 / 이전 작업 인용 > 교과서 미대조
